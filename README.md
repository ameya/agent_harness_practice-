# Agent Harness Lab — Codex Handoff

This repository begins as a specification-first learning project for implementing a custom Python Agent Harness. Start Codex using `CODEX_START_PROMPT.md`. The `AGENTS.md` file defines repository conventions; `specs/R00_SPEC.md` defines first-release acceptance criteria; `specs/ROADMAP.md` defines later phases. Codex should replace this placeholder README with runnable local instructions during R00 implementation.

The first release must run locally using a deterministic fake model, optionally using local Ollama. No API keys, online dependencies at runtime, or actual production systems are required for the baseline.
